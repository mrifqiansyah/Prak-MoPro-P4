IMPLEMENTATION ROADMAP & DEVELOPMENT PHASES:

Tahap 1: Konfigurasi Dependensi
- Menambahkan dependensi package ke `pubspec.yaml`:
  * `shared_preferences` untuk penyimpanan key-value.
  * `hive` dan `hive_flutter` untuk penyimpanan NoSQL Box.
  * `sqflite`, `path`, dan `sqflite_common_ffi` untuk database relasional SQLite.
- Menjalankan `flutter pub get`.

Tahap 2: Inisialisasi Database Lokal di lib/main.dart
- Menjalankan `WidgetsFlutterBinding.ensureInitialized()`.
- Menyiapkan FFI loader SQFlite untuk dukungan desktop.
- Menginisialisasi Hive Flutter dan membuka Box (`contacts_box`).

Tahap 3: Modul 1 - Notes App (SharedPreferences)
- Penyimpanan berbasis key-value (`getStringList` & `setStringList`).
- Operasi CRUD catatan sederhana di `lib/pages/notes_app/notes_home.dart`.

Tahap 4: Modul 2 - Contact App (Hive)
- Penyimpanan NoSQL berbasis Box.
- Operasi CRUD data kontak (nama, nomor telepon) di `lib/pages/contact_app/contact_home.dart`.

Tahap 5: Modul 3 - Task App (SQFlite)
- Pembuatan model data relasional di `lib/data/task_model.dart`.
- Pembuatan helper database dan skema tabel SQL di `lib/services/database_helper.dart`.
- Operasi CRUD lengkap (Insert, Query, Update, Delete) di `lib/pages/sqflite_app/sqflite_home.dart`.

Tahap 6: Menu Utama & Navigasi
- Memperbarui `lib/pages/main_app.dart` dengan navigasi ke ketiga teknologi storage.

Tahap 7: Dokumentasi & Uji Coba
- Pembuatan berkas laporan `DOKUMENTASI_LOCAL_STORAGE.md` berisi perbandingan SQFlite vs Hive vs SharedPreferences, struktur tabel, dan panduan presentasi/tugas praktikum.
